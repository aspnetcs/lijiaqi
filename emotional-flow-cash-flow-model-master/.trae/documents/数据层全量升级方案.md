# 数据层全量升级方案

## Context（为什么做这个升级）

用户上传了《如何获取真实的股票数据，用于量化投资相关的系统》文档，要求按文档推荐完成系统。当前系统数据层存在以下与文档最佳实践的差距：

1. **数据源混乱**：个股用腾讯 fqkline、指数用新浪、北向/两融用 akshare，且腾讯接口的 `amount` 列恒为 0，导致 Amihud 非流动性因子失真。
2. **无财务/基本面数据**：文档建议 Tushare 补财务，当前完全缺失。
3. **无数据清洗**：涨跌停、停牌、ST、复牌、缺失值未处理。
4. **幸存者偏差**：用当前沪深 300 成分股回测历史，退市/被剔除股被忽略。
5. **CSV 存储**：文档推荐 Parquet/SQLite，列数查询慢。
6. **无交叉验证**：单一数据源无质量校验。

用户选择**全量升级**，且**没有 Tushare token**（ChatGPT Plus 不可用）。因此方案：AKShare 主源 + BaoStock 交叉验证 + 财务数据 + 数据清洗 + Parquet 落库；历史成分股用 AKShare 当前成分 + 预留 Tushare 接入点。

## 实现步骤

### Step 1：安装依赖
```
pip install baostock pyarrow
```

### Step 2：扩展 `src/config.py`
- `DataConfig` 新增：`stock_daily_pq_dir`、`index_daily_pq_dir`、`north_bound_pq_dir`、`margin_trade_pq_dir`、`financial_dir`、`constituents_dir`、`data_quality_log_dir`
- 新增 `tushare_token: str = ""`（从 gm_config.json 或环境变量读取，留空则不用）
- 新增 `DataQualityConfig`：`threshold=0.005`、`enable_baostock=True`、`sample_ratio=0.05`
- `SystemConfig` 新增 `data_quality` 字段

### Step 3：新建 `src/data_cleaning.py`（独立模块，无依赖）
函数：
- `detect_limit_up_down(df, code)` → 新增 `is_limit_up`/`is_limit_down`（主板±10%、创业板/科创板±20%、ST±5%、北交所±30%）
- `detect_suspension(df)` → `is_suspended`（volume==0 或一字且量极小）
- `detect_resume(df)` → `is_resume`（前停今开）
- `mark_st(df, stock_name)` → `is_st`
- `fill_missing(df, date_col="eob")` → 重建交易日历、前向填充、`was_filled` 标记
- `clean_stock_daily(df, code, stock_name="")` → 一站式入口

### Step 4：新建 `data/fetch_data_akshare.py`（统一下载器，替代 fetch_market_data.py）
AKShare 接口（已确认有效）：
| 数据 | 接口 | 关键列 |
|------|------|--------|
| 个股日线(qfq) | `ak.stock_zh_a_hist(symbol, period="daily", start_date, end_date, adjust="qfq")` | 日期/开盘/收盘/最高/最低/成交量/成交额/换手率/涨跌幅 |
| 指数日线 | `ak.stock_zh_index_daily(symbol="sh000300")` | date/open/high/low/close/volume |
| 北向资金 | `ak.stock_hsgt_hist_em(symbol="沪股通"/"深股通")` | 日期/当日成交净买额 |
| 两融(上交所) | `ak.stock_margin_sse(start_date, end_date)` | 信用交易日期/融资融券余额/融资余额 |
| 业绩报表 | `ak.stock_yjbb_em(date=报告期)` | 股票代码/净利润/营业收入/EPS/ROE |
| 财务指标 | `ak.stock_financial_analysis_indicator(symbol, start_year)` | 净资产收益率/资产负债率/... |
| 历史估值(PE/PB) | `ak.stock_zh_valuation_baidu(symbol, indicator="市盈率"/"市净率")` | date/value |
| 成分股 | `ak.index_stock_cons_csindex(symbol="000300")` | 成分券代码/成分券名称 |

输出：每类数据同时写 CSV（兼容旧代码）+ Parquet（新优先）。个股下载后立即调用 `clean_stock_daily` 清洗再落盘。支持 `--types stock index north margin financial constituents` 和 `--validate` 触发交叉验证。

### Step 5：新建 `src/data_quality.py`（BaoStock 交叉验证）
- `CrossValidator` 类：AKShare vs BaoStock 前复权收盘价对比，差异>0.5% 记日志到 `logs/data_quality_YYYYMMDD.log`
- `run_batch(codes, sample_ratio=0.05)`：抽样验证，不阻塞主流程
- BaoStock 登录失败则跳过，不抛异常

### Step 6：新建 `src/financial_reader.py` + `src/constituents_reader.py`
- `FinancialReader`：读 `financial/daily_basic_pq/{code}.parquet`（PE/PB/换手率/市值）、`yjbb_pq/`（业绩）、`indicator_pq/`（财务指标）
- `ConstituentsReader.get_hs300(date)`：优先用 Tushare 历史权重（若 token 存在且有数据），否则降级当前成分股并打印幸存者偏差 WARNING

### Step 7：改造 `src/data_reader.py`（保持公共接口不变）
- 新增 `_safe_read_parquet(path)`
- `StockDailyReader.load_single`：优先读 `stock_daily_pq/{code}.parquet`，降级 CSV；旧 CSV 缺标记列时内存中调用 `clean_stock_daily` 补齐
- 新增 `_normalize_columns(df)`：AKShare 中文列名 → 英文 `eob/open/high/low/close/volume/amount/turnover/change_pct`
- 北向/两融 Reader 同理 parquet 优先
- 新增 `get_stock_daily_basic(code, date)`、`get_hs300_constituents(date)` 聚合方法
- **关键**：`get_stock_daily`/`get_index`/`get_north_bound`/`get_margin_trade` 的签名和返回前 7 列名保持不变，确保 main.py、mcp_server.py、各引擎零改动

### 不改的文件
`main.py`、`mcp_server.py`、`sentiment_engine.py`、`capital_flow.py`、`triple_layer.py`、`fusion_engine.py`、`tests/`

## 风险与对策
- AKShare 接口改名：每个接口 try/except，失败打印明确错误并降级现有 CSV。
- `stock_zh_a_daily_basic` 不存在：用 `stock_zh_valuation_baidu`（历史 PE/PB）替代。
- BaoStock 登录失败：捕获异常，跳过验证不阻塞。
- 前复权基准日差异：交叉验证仅比较相对涨跌幅，允许首日差异。
- 退市股无数据：记录到 `download_failures.log`，不中断。
