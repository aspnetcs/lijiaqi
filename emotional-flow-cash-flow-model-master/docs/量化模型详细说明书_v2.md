## 1. 系统概述

### 1.1 一句话描述

每周自动判断"该不该买、该买多少、该买什么"，然后模拟执行交易，记录净值曲线。

### 1.2 核心设计思想

系统采用**三层递进决策**架构，模拟人类投资者的决策链条：

```
第一层（宏观）  → 判断市场大环境，决定该投多少钱
第二层（板块）  → 看哪些行业在"热"，锁定选股范围
第三层（个股）  → 在热门行业中挑具体股票
```

每层独立运行，通过标准接口传递数据。层间解耦意味着任一层可以独立优化，不影响其他层。

### 1.3 类与接口设计

系统遵循面向对象原则，共 10 个核心类：

| 类 | 文件 | 职责 | 对外接口 |
|---|------|------|----------|
| `DataReader` | data_reader.py | 数据读写、缓存、多格式支持 | `get_stock_daily()`, `get_benchmark()` |
| `MacroLayer` | triple_layer.py | 宏观择时 | `compute_signal(date, sentiment) -> MacroSignal` |
| `SectorLayer` | triple_layer.py | 行业板块筛选 | `select_sectors(matrix, date) -> SectorSignal` |
| `StockLayer` | triple_layer.py | 个股多因子选股 | `pick_stocks(pool, data) -> List[StockScore]` |
| `SentimentEngine` | sentiment_engine.py | 情绪分析 | `analyze(date, texts) -> SentimentResult` |
| `CapitalFlowAnalyzer` | capital_flow.py | 资金流分析 | `analyze_stock(df, date) -> FlowResult` |
| `FusionEngine` | fusion_engine.py | 信号融合 | `fuse(sent, flow, macro) -> FusionResult` |
| `ResultExporter` | result_exporter.py | 可视化输出 | `export_all(nav, bench, ...) -> Dict[str, str]` |
| `CMFCalculator` | capital_flow.py | 柴金资金流 | `compute(df) -> pd.Series` |
| `FactorCalculator` | capital_flow.py | 七因子计算 | `compute_all(df) -> Dict[str, float]` |

**个股日线加载**：
```
读取 CSV → parse date → 处理停牌/缺失 → 缓存到内存字典
                                     ↓
                             后续读取命中缓存 (性能优化)
```

```
国泰安ZIP (367万行原始数据)
    → 解压读取
    → 按 TradeDate 日聚合 (sum balance)

    → DataReader 加载缓存

```

```
    → 清洗格式 (去除空行/乱码)
    → jieba分词 → 提取正负面词频
    → 按日期索引 → Pickle保存
    → DataReader 按日期范围快速检索
```

## 4. 信号生成层详解

### 4.1 宏观层 (MacroLayer)

**功能**：判断全市场大环境，输出仓位上限 [0.05, 1.0]

**三个子信号**：

#### 4.1.1 北向资金评分

```
算法：MA背离度 + 趋势方向
  MA5 = 北向净流入的5日均值
  MA20 = 北向净流入的20日均值
  背离度 = (MA5 - MA20) / max(|MA20|, 历史均值×0.1, 1e-8)
  趋势 = clip(MA20 / 历史均值, -1, 1)
  北向评分 = clip(背离度×3.0 + 趋势×0.3, -1, 1)
```

- 背离度>0：外资近期在加速流入 → 看多
- 背离度<0：外资在流出 → 看空

#### 4.1.2 融资融券评分

```
算法：余额5日变化率
  两融评分 = clip(5日余额变化率 / 5%, -1, 1)
```

- +5%变化 → +1.0（杠杆资金积极加仓）
- -5%变化 → -1.0（杠杆资金恐慌撤退）

#### 4.1.3 LPPL 泡沫检测

用 Log-Periodic Power Law 模型检测指数是否处于泡沫状态。拟合 500 天历史价格，当模型参数 `m<0.8` 且 `C/B>0.15` 时判定为泡沫。检测到泡沫 → 当前仓位 ×0.6（最低保留 0.15）。

#### 4.1.4 综合公式

```
基础仓位 = 0.4 + 0.3×北向评分 + 0.25×两融评分
基础仓位 = clip(基础仓位, 0.05, 1.0)
if LPPL泡沫: 基础仓位 = max(基础仓位×0.6, 0.15)
最终仓位上限 = clip(基础仓位 + 情绪×0.15, 0.05, 1.0)

市场状态判定:
  仓位 > 0.45 → BULL
  仓位 < 0.25 → BEAR
  其他      → SIDEWAYS
```

### 4.2 情绪引擎 (SentimentEngine)

**功能**：判断全市场情绪热度，输出 [-1, +1] 得分

**双通道融合**：

```
通道A（文本情绪）：
  调研纪要文本 → jieba分词 → 情感词典匹配 → 文本情绪得分
  权重: 0.3 (有文本时)

通道B（代理情绪）：
  沪深300近20天数据 →
    0.4×上涨天数占比 (ADR)
    + 0.3×成交量异常度
    + 0.3×收益率偏度
  权重: 0.7 (有文本时) / 1.0 (无文本时)
```

**情感词典**：60+正面词 + 60+负面词，辅以否定词翻转（"不是很好"→负面）和程度副词加权（"大幅上涨"→×1.5）。

**文本数据量**：调研纪要 + 投资者互动合并后共 231 万条，日均约 2,100 条，选取最近 7 天文本进行分析。

---

### 4.3 资金流分析 (CapitalFlowAnalyzer)

**功能**：判断全市场资金方向，输出 [-1, +1] 方向占比

**创新算法**（不取均值，改用方向占比计数法）：

```
对候选股票池 (最多800只) 按板块等比例取样:
  每只股票计算资金流得分 (CMF + OBV + 微观因子)

if 得分 > +0.05 → 流入股 (count++)
if 得分 < −0.05 → 流出国 (count++)

方向占比 = (流入股数 − 流出国数) / 总取样数
结果: [−1, +1]
  +1 = 全部资金流入
  −1 = 全部资金流出
```

**每只股票的资金流得分因子**：

| 因子 | 权重 | 计算方法 |
|------|:----:|----------|
| cmf_turn | 35% | 短期CMF均值 − 长期CMF均值 |
| vol_20d | 18% | 20日收益率标准差 |
| mom_20d | 15% | 20日累计收益率 |
| overnight_ret | 10% | (今日开盘−昨日收盘)/昨日收盘 |
| vol_rs | 10% | 5日均量 / 20日均量 |
| cmf_20 | 7% | 柴金资金流 20日均值 |
| illiq | 5% | Amihud 非流动性指标 |

**CMF (柴金资金流) 计算公式**：

```
MFM = ((收盘−最低) − (最高−收盘)) / (最高−最低)
CMF_20 = Σ(MFM_i × Volume_i, i=1..20) / Σ(Volume_i, i=1..20)
```

- MFM>0：收盘价靠近当天最高价 → 资金在主动买入
- CMF>0：过去20天整体资金净流入

## 5. 选股层详解

### 5.1 板块筛选 (SectorLayer)

**算法**：基于行业资金流矩阵，计算每个行业的资金流加速排名。

```
近期4天均值 = mean(最近4天行业CMF)
前期4天均值 = mean(前4天行业CMF)
变化量 = 近期4天 − 前期4天
加速量 = 最近2天 − 最近4天
行业得分 = 0.6×变化量 + 0.4×加速量

筛选: 得分>0 且排名前5 → 流入板块
     得分<0 且排名后5 → 流出板块
```

### 5.2 个股选股 (StockLayer)

**三步流程**：

```
Step 1: 因子计算
  FactorCalculator.compute_all(df) → 7个因子的原始值

Step 2: 截面rank打分
  所有候选股按每个因子排名 → 百分位 (0~1)
  乘以因子方向 (+1或−1)
  乘以因子权重
  总分 = Σ加权分

Step 3: 双验证过滤
  条件A: 价格 > MA20 (技术面)
  条件B: CMF > 0 (资金面)
  高仓位(>0.5): A AND B
  低仓位(≤0.5): A OR B
  都不满足 → 淘汰
```

**7因子方向与权重**：

| 因子 | 权重 | 默认方向 | 牛市方向 | 含义 |
|------|:----:|:-------:|:-------:|------|
| cmf_turn | 0.35 | +1 | +1 | 资金拐头，越大越好 |
| vol_20d | 0.18 | −1 | +1 | 震荡市要低波，牛市要高波 |
| mom_20d | 0.15 | −1 | +1 | 震荡市反转，牛市动量 |
| overnight_ret | 0.10 | −1 | +1 | A股高开常被砸盘 |
| vol_rs | 0.10 | −1 | +1 | 缩量好 vs 放量好 |
| cmf_20 | 0.07 | −1 | +1 | CMF低=被低估 |
| illiq | 0.05 | +1 | +1 | 流动性，A股特有 |

**板块集中度约束**：

- 最多持仓 **10 只**
- 同一行业最多 **3 只**
- 若板块内候选不足，自动放宽到全候选池

## 6. 融合决策层详解

### 6.1 天花板 × 油门模型 (v2核心)

```
宏观仓位上限 = 天花板 (宏观层的直接输出)
方向信号 = w_s×情绪 + w_f×资金流
执行比率 = (方向信号 + 1) / 2   (将[−1,+1]映射到[0,1])
最终仓位 = 宏观仓位上限 × 执行比率
```

### 6.2 动态权重

| 市场状态 | 判定条件 | 情绪 | 资金流 | 策略 |
|----------|:-------:|:----:|:-----:|------|
| BULL | 宏观>0.45 | 30% | **70%** | 趋势中资金流主导 |
| SIDEWAYS | 0.25~0.45 | 50% | 50% | 震荡等权 |
| BEAR | 宏观<0.25 | **60%** | 40% | 防守时情绪敏感 |
| EXTREME | 情绪绝对值>0.7 | **70%** | 30% | 极端情绪主导 |

### 6.3 执行约束

```
牛市下限: execution ≥ 0.40 (防踏空)
熊市上限: execution ≤ 0.60 (加强防守)
极端市: position ≤ 0.50
```

### 6.4 冲突仲裁与质量调整

- **冲突仲裁**：当情绪和资金流方向相反时，执行比率向 0.5 中性回归
- **质量调整**：当三通道一致性低时，执行比率向 0.5 回归

### 6.5 数值举例

**震荡市偏多**：
```
宏观=0.50, 情绪=+0.20, 资金流=+0.30
→ SIDEWAYS, w_s=0.5, w_f=0.5
→ 方向 = 0.5×0.20 + 0.5×0.30 = 0.25
→ 执行 = (0.25+1)/2 = 0.625
→ 仓位 = 0.50 × 0.625 = 31.25%
```

**熊市谨慎**：
```
宏观=0.20, 情绪=+0.10, 资金流=−0.15
→ BEAR, w_s=0.6, w_f=0.4
→ 方向 = 0.6×0.10 + 0.4×(−0.15) = 0.0
→ 执行 = (0+1)/2 = 0.5, 但BEAR限≤0.6 → 0.5
→ 仓位 = 0.20 × 0.5 = 10%
```

## 7. 交易执行层详解

### 7.1 调仓节奏

- **调仓频率**：每周第一个交易日
- **初始资金**：1,000 万元
- **估值频率**：每日（按收盘价）
- **仓位分配**：等权（每只股票相同份额）

### 7.2 调仓日完整流水线

```
① 止损检查   → 单股跌幅≥8%立即清仓
② 缓存清理   → 清除5天前缓存的数据
③ 情绪分析   → 近7天调研纪要词典打分 + 行情代理
④ 宏观择时   → 北向MA + 两融变化 + LPPL → 仓位上限
⑤ 板块筛选   → 行业资金流加速排名 → 流入TOP5
⑥ 构建候选池 → 流入板块内股票，最多800只，等比例取样
⑦ 资金流分析 → CMF方向占比 → 资金流得分 [−1,+1]
⑧ 融合决策   → 天花板×执行比率 → 最终仓位
⑨ 选股       → 7因子rank + 双验证 → TOP-N只
⑩ 调仓执行   → 卖出不在目标的 / 买入目标的
⑪ 保存checkpoint → 支持断点续传
```

### 7.3 交易成本

| 费用 | 比率 | 扣费时机 |
|------|:----:|----------|
| 佣金 | 0.05% | 买入 + 卖出 |
| 印花税 | 0.10% | 仅卖出 |

### 7.4 止损机制

```
止损条件: (当前价 − 成本价) / 成本价 < −8%
触发动作: 立即清仓该股
调仓日检查: 每只持仓股逐一检查
```

### 7.5 断点续传

每个调仓日结束后保存 checkpoint（pickle 格式），包含：

- 当前持仓 (holdings)
- 当前现金 (cash)
- 净值历史 (nav_history)
- 融合结果 (fusion_results)
- 已处理日期 (last_processed_date)

运行参数：
- `--resume`：从断点恢复
- `--clean`：清除断点重新开始
- 回测完成后自动清除 checkpoint

## 9. 版本改进对比

### 9.1 v2 相对初始版本的全部改进

| 类别 | 问题 | 初始版本 | v2 修复 |
|------|------|----------|---------|
| **数据** | 北向除零NaN | 无保护，导致策略10个月不交易 | 分母加 1e-8 硬底 + NaN→0 三路兜底 |
| **数据** | 融资融券为空 | margin_score 始终为0 | 从国泰安ZIP提取367万行数据日聚合 |
| **数据** | 行业分类粗 | 28个行业，同行业内差异大 | 申万二级124行业 (westock-data获取) |
| **数据** | 情绪文本少 | 仅5条新闻/天，信息量低 | 调研纪要+投资者互动231万条，日均2100条 |
| **算法** | 资金流均值化 | 200只股票取平均→趋近0 | 方向占比计数法：流入股占比−流出国占比 |
| **算法** | 选股有偏向 | 按插入顺序取前200只 | 按板块等比例取样，取消数量上限 |
| **算法** | BULL阈值高 | 0.60，牛市识别延迟 | 降至0.45 |
| **算法** | EMA平滑慢 | 9月暴涨仓位卡26% | 完全移除EMA平滑和±20%仓位变动限制 |
| **算法** | 融资融券无用 | 数据缺失，评分恒为0 | 补齐968个交易日数据 |
| **工程** | 无断点续传 | 长时间回测中断需重跑 | pickle checkpoint + --resume/--clean |
| **工程** | 无止损机制 | 单股无限亏损 | 8%硬止损 |
| **风格** | overnight方向错 | +1（正向），A股高开常被砸 | 修正为−1（负向） |
| **风格** | 止损误判 | 熊市非调仓日跌破8%无法止损 | 调仓日统一检查止损 |

### 9.3 v2 的已知局限

| 限局 | 影响 | 改进方向 |
|------|------|----------|
| 选股因子偏防守 | 牛市中难跑赢基准 | 宏观regime控制仓位而非改因子 |
| 宏观仓位上限低 | 牛市最大仓位50%左右 | 提高基础仓位或降低BULL阈值 |
| 文本情绪权重低 | 大量纪要信息被稀释 | 提升权重或独立加权 |
| 无对冲机制 | 纯多头，熊市只能减仓 | 增加股指期货/ETF对冲 |

### 9.4 模型迭代路线回顾

```
v0 初始 → v2 补数据+修bug → 回测+6.32%
                              ↓
                  v3 个股追涨 → +3.59% (更差)
                              ↓
                  v3.1 放宽追涨 → −2.25% (更差)
                              ↓
                  v4 固定仓位版 → −0.94% (持平)
                              ↓
          ←-- 回归 v2 (最优！)
```

**结论**：多次迭代表明，v2 的防守型因子 + 简单宏观公式组合在风险控制上最优。过度优化（放宽仓位、加入复杂状态机）反而导致过拟合，样本外表现更差。
