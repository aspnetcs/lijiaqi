## 二、逐层问题诊断

### 2.1 数据层 (DataReader)

**现状**: 正常工作, 5062只股票日线已下载

**问题**: 无

### 2.2 情绪层 (SentimentEngine)

**现状**:
- 新闻数据为空 (news_data/ 目录无文件)
- 完全依赖 MarketSentimentProxy 计算
- MarketSentimentProxy 用沪深300的 close/volume 推算

**问题**:
- **情绪信号被严重稀释**: ADR/成交量异常度/偏度 都基于沪深300一只指数, 不是全市场情绪
- **情绪范围过窄**: composite_sentiment 始终在 [-0.3, +0.3] 之间, 无法产生强信号
- **EMA平滑进一步压缩**: alpha=0.3 让信号更加钝化

**根因**: 情绪引擎缺乏真实文本数据, 退化为指数技术指标代理, 信息量很低

### 2.3 资金流层 (CapitalFlowAnalyzer)

**现状**:
- 用选股池内最多200只股票计算 flow_score 均值
- flow_score = 0.4*cmf + 0.3*cmf_turn + 0.3*obv_chg

**问题**:
- **均值化抹平信号**: 200只股票的CMF取平均, 必然趋近于0 (有的正有的负)
- **CMF周期过长**: 用20日CMF, 反应慢, 在快速反转行情中滞后
- **obv_change_pct 没归一化**: 5日变化率可能极大或极小, 拉偏综合得分

**根因**: 全市场平均资金流必然中性, 应该用"资金净流入股票占比"或"强势股资金流"作为信号

### 2.4 三层决策

#### L1 宏观层 (MacroLayer)

**现状**:
- north_score: MA5 vs MA20 比较, 返回 {-1, 0, 0.5, 1}
- margin_score: 5日变化率, 返回 {-1, 0, 0.5, 1}
- LPPL泡沫检测: 拟合500天数据, 慢但有效
- 基础仓位 = 0.3 + 0.2*north + 0.2*margin

**问题**:
- **margin_df 为空**: 回测日志显示 "融资融券: 0 行", margin_score 始终为0
- **基础仓位上限低**: north=1 + margin=0 = 0.5, 最大也就 0.5+情绪调整
- **熊市判定门槛过低**: macro < 0.3 = bear, 而上限就0.5, 极易触发
- **情绪调整方向反了**: `base_pos + sentiment_score*0.15`——sentiment=+0.5 时加仓, 但sentiment是基于指数涨幅计算的, 涨多了加仓 = 追高

**根因**: margin数据缺失 + 仓位上限设计不合理 + 情绪调整方向存在追涨杀跌风险

#### L2 板块层 (SectorLayer)

**现状**:
- 基于 sector_money_flow/ 目录的CSV
- 计算近10日CMF的 delta*0.6 + accel*0.4
- 取评分前5为流入, 后5为流出

**问题**:
- **板块名不匹配**: L2 返回的行业名 (如"电子") 与 _stock_industry_map.json 中的映射可能对不上
- **流入板块内股票被硬过滤**: pick_stocks 中 `if ind not in selected_sectors: continue` 容易清空候选池
- **板块评分基于绝对CMF**: 高基数行业永远排前, 低基数行业永远排后

**根因**: 板块筛选与个股映射存在命名不一致问题

#### L3 选股层 (StockLayer)

**现状**:
- 7个因子截面rank, 加权打分
- 双验证: 高仓位要求 above_ma20 AND cmf>0; 低仓位 OR

**问题**:
- **vol_20d 权重过高 (0.18) + 负向**: 偏好低波动股, 牛市中低波股往往跑输
- **mom_20d 负向 (反转) + 权重0.15**: 偏好近期下跌的股票, 趋势行情中持续亏
- **cmf_turn 权重最高 (0.35)**: 资金拐头信号, 但2日vs5日窗口太短, 噪音大
- **双验证门槛过高**: 要求价格在MA20上方 + CMF为正, 把"超跌反弹"的好机会全过滤了
- **overnight_ret 方向反了**: 设置为+1 (正向), 但实际上A股隔夜高开常被砸盘, 应该是负向

**根因**: 因子组合本质是"反转+低波"风格, 在2024年H1的反弹行情中风格错配

### 2.5 融合层 (FusionEngine)

**现状**:
- 4种市场状态对应不同权重
- SIDEWAYS: 情绪0.40 + 资金流0.35 + 宏观0.25
- BEAR: 情绪0.20 + 资金流0.55 + 宏观0.25

**问题**:
- **权重设计反逻辑**: BEAR状态下资金流权重反而最高(0.55), 但资金流均值必然中性, 导致熊市仓位偏高
- **conflict_adj = 0.5 半仓**: 冲突时直接砍半, 但2024年冲突频繁, 仓位被系统性压低
- **sent_norm 映射错位**: `sent_norm = (sentiment + 1) / 2`, 把[-1,1]映射到[0,1], 但sentiment本身就在[-0.3, +0.3], 映射后变成[0.35, 0.65], 接近0.5中性, 无法产生强信号
- **BEAR判定阈值0.3过低**: macro_score=0.25就判定熊市, 但macro_score=0.5已经不算低了

**根因**: 融合层对"中性信号"过度敏感, 把本来就不强的信号又压平了

### 2.6 回测引擎

**现状**: 按交易日估值, 周调仓

**问题**:
- **买入用整手向下取整**: `int(delta/price)`, 10元股票100万仓位 = 10万股, 但剩余零头无法买入, 长期累积误差
- **无最小持仓数限制**: 可能买到只够买100股的股票, 交易成本占比过高
- **无止损/止盈**: 单股亏损无上限
- **板块集中度约束 max_per_sector=3 过严**: 流入板块只有5个, 每板块3只 = 最多15只, 但max_holdings=10, 实际可能选不够

## 四、改进方案

### 4.1 P0 修复: 因子风格自适应

**问题**: 固定的"反转+低波"风格在反弹行情中必败

**方案**: 根据市场状态切换因子方向

```python
# 在 StockLayer 增加 regime-aware 因子方向
def _get_directions_by_regime(self, regime):
    if regime in ('bull', 'extreme_bull'):
        # 趋势行情: 动量正向 + 高波 (追涨杀跌)
        return {
            "cmf_turn": +1, "vol_20d": +1, "mom_20d": +1,
            "overnight_ret": +1, "vol_rs": +1,
            "cmf_20": +1, "illiq": +1,
        }
    else:
        # 震荡/熊市: 保持反转+低波 (原配置)
        return self.directions
```

### 4.2 P0 修复: 资金流信号重构

**问题**: 200只股票均值必然趋近于0

**方案**: 改用"强势股资金流"

```python
# 不取均值, 而是计算资金净流入股票的占比
def compute_flow_signal(stock_data_dict):
    scores = []
    for sym, df in stock_data_dict.items():
        result = flow_analyzer.analyze_stock(df)
        scores.append(result.flow_score)
    
    # 信号 = 流入股票占比 - 流出股票占比
    inflow_count = sum(1 for s in scores if s > 0.1)
    outflow_count = sum(1 for s in scores if s < -0.1)
    total = len(scores)
    if total == 0:
        return 0.0
    return (inflow_count - outflow_count) / total  # [-1, 1]
```

### 4.3 P1 修复: 情绪信号增强

**问题**: 无新闻数据, 退化为技术指标

**方案**:
1. **短期**: 增加市场宽度指标 (涨跌家数比、涨停跌停比), 数据可从全市场日线计算
2. **中期**: 接入 akshare 的财经新闻接口, 下载到本地 news_data/

```python
# 增加市场宽度情绪
def compute_market_breadth(all_stocks, date):
    """用全市场涨跌家数计算情绪"""
    up = 0; down = 0; limit_up = 0
    for sym in all_stocks:
        df = reader.get_stock_daily(sym, date, date)
        if df is None or len(df) < 2: continue
        ret = df['close'].iloc[-1] / df['close'].iloc[-2] - 1
        if ret > 0: up += 1
        elif ret < 0: down += 1
        if ret > 0.095: limit_up += 1
    breadth = (up - down) / (up + down + 1e-6)
    return breadth  # [-1, 1]
```

### 4.4 P1 修复: margin 数据补全

**问题**: 融资融券数据为空, macro_score 上限被压到0.5

**方案**:
1. 运行 `python data/download_data.py --data-types margin_trade` 下载
2. 如果数据源不可用, 用北向资金替代: north_score * 1.5 (上限1.0)

### 4.5 P1 修复: 融合权重调整

**问题**: BEAR状态给资金流高权重, 但资金流均值中性

**方案**:
- BEAR状态: 提高宏观权重 (防守为主, 跟随大盘仓位)
- SIDEWAYS状态: 提高情绪权重 (情绪是震荡市的关键变量)

```python
REGIME_WEIGHTS = {
    MarketRegime.BULL:      {"sentiment": 0.25, "capital_flow": 0.50, "macro": 0.25},
    MarketRegime.BEAR:      {"sentiment": 0.15, "capital_flow": 0.30, "macro": 0.55},  # 宏观主导
    MarketRegime.SIDEWAYS:  {"sentiment": 0.45, "capital_flow": 0.30, "macro": 0.25},  # 情绪主导
    MarketRegime.EXTREME:   {"sentiment": 0.50, "capital_flow": 0.30, "macro": 0.20},
}
```

### 4.6 P2 修复: 双验证放宽

**问题**: above_ma20 AND cmf>0 过滤掉超跌反弹机会

**方案**: 改为三选二验证

```python
def dual_verification(self, stock_data, position_ratio):
    above_ma = close.iloc[-1] > ma20
    cmf_positive = cmf.iloc[-1] > 0
    cmf_turning = cmf.iloc[-1] > cmf.iloc[-3]  # CMF拐头向上
    
    signals = [above_ma, cmf_positive, cmf_turning]
    return sum(signals) >= 2  # 三选二
```

### 4.7 P2 修复: overnight_ret 方向

**问题**: A股隔夜高开常被砸盘, 不应作为利好

**方案**: 方向改为 -1

```python
self.directions["overnight_ret"] = -1  # 隔夜高开反向
```

### 4.8 P2 修复: 板块命名兼容

**问题**: L2返回的行业名与个股映射不一致

**方案**: 在 pick_stocks 中增加模糊匹配

```python
def _match_sector(self, ind, selected_sectors):
    if ind in selected_sectors:
        return True
    # 模糊匹配: "电子" 匹配 "电子信息"、"电子设备"
    for sec in selected_sectors:
        if ind in sec or sec in ind:
            return True
    return False
```
